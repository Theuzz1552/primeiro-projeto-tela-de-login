# 🔐 Modern Login UI

Uma interface moderna de tela de login desenvolvida para praticar conceitos de desenvolvimento Front-end, design de interfaces e responsividade.

⚠️ **Aviso:** 
Este projeto tem como objetivo demonstrar apenas a interface (UI) de um sistema de autenticação. As telas de Login e Cadastro não possuem integração com banco de dados ou API e, portanto, não realizam autenticação de usuários.


## 📸 Preview

[Tela de Login](img/tela-de-fundo.png)


## ✨ Funcionalidades da Interface

* Interface moderna e minimalista
* Layout responsivo
* Tela de login
* Campos de e-mail e senha
* Opção "Lembrar de mim"
* Link "Esqueceu a senha" (apenas interface)
* Link para cadastro (apenas interface)
* Estrutura preparada para futura integração com autenticação
* Código organizado


## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3


## 🎯 Objetivo

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em **Análise e Desenvolvimento de Sistemas**, com foco na criação de interfaces modernas e na aplicação de boas práticas de desenvolvimento Front-end.

O objetivo foi reproduzir uma experiência visual profissional de uma tela de login, preparando a estrutura para futuras integrações com serviços de autenticação.
